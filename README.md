# Election Archive

Quero reconstruir completamente este site no Lovable como uma página de vendas premium para um produto digital chamado ANTES DE VOTAR EM LULA — ARQUIVO ELEITORAL 2026.

O site deve parecer uma experiência de arquivo confidencial + investigação documental + jornalismo investigativo premium, e não um site comum de e-book.

A referência visual principal é a imagem fornecida anteriormente: fundo preto/grafite, vermelho escuro e vermelho intenso, documentos antigos, carimbos CONFIDENCIAL, ruído/grain, scanner, arquivos classificados, tipografia condensada e pesada, sombras cinematográficas e atmosfera de investigação.

O resultado precisa ser extremamente profissional, responsivo, rápido e visualmente impactante.

1. IDENTIDADE VISUAL

Paleta principal:

preto quase absoluto;

grafite;

cinza carvão;

branco envelhecido/off-white;

vermelho escuro;

vermelho intenso para elementos de destaque.

NÃO usar:

verde;

azul;

roxo;

gradientes coloridos genéricos;

estética de landing page de curso;

visual de template pronto;

emojis.

A aparência deve lembrar:

arquivo confidencial;

documentos governamentais;

investigação jornalística;

sala de inteligência;

documentos classificados;

dossiê físico;

thriller documental;

revista investigativa premium.

Adicionar textura visual muito sutil de papel, poeira, scanner, riscos e grain.

Os efeitos devem ser elegantes e discretos. Não exagerar.

2. FUNDO DINÂMICO

Criar um fundo preto/grafite dinâmico durante toda a página.

Adicionar elementos muito sutis se movimentando lentamente:

documentos desfocados;

códigos;

números de arquivo;

linhas técnicas;

pequenos carimbos;

partículas de poeira;

textura de scanner;

ruído cinematográfico;

pequenos flashes de luz;

linhas vermelhas extremamente discretas.

O movimento deve ser lento e sofisticado.

Nada deve prejudicar a leitura.

O site deve parecer vivo, como se o visitante estivesse navegando por um arquivo digital real.

3. HERO / PRIMEIRA TELA

A primeira tela deve ocupar praticamente toda a viewport.

Usar a imagem fornecida como imagem principal do hero, preservando a fotografia e o grande X vermelho sobre o rosto.

Sobre a imagem, criar uma composição editorial.

6. SEÇÃO "FATOS OU ALEGAÇÕES?"

Essa seção é MUITO importante.

Criar uma interface visual premium explicando que o arquivo não deve misturar fatos comprovados com alegações.

Criar quatro etiquetas:

COMPROVADO
Informação respaldada por documento ou fonte primária.

ALEGAÇÃO
Afirmação feita por determinada pessoa, órgão ou parte envolvida.

DECISÃO JUDICIAL
Informação decorrente de decisão de tribunal.

CONTEXTO / INTERPRETAÇÃO
Análise ou interpretação apresentada separadamente dos fatos.

Texto:

"A diferença entre uma acusação e uma condenação importa. A diferença entre uma declaração e um fato também."

Isso deve aumentar a credibilidade do produto.

15. RESPONSIVIDADE

O site precisa funcionar perfeitamente em:

desktop;

notebook;

tablet;

celular.

No celular:

documentos devem se reorganizar verticalmente;

botões devem ocupar largura adequada;

preço deve continuar extremamente visível;

imagem do hero deve permanecer impactante;

nenhum elemento pode causar scroll horizontal.

16. PERFORMANCE

O site deve carregar rapidamente.

Otimizar imagens.

Lazy-load nas imagens abaixo do hero.

Evitar bibliotecas pesadas desnecessárias.

Manter animações em CSS/JS leves.

17. REGRA EDITORIAL ABSOLUTA

Não inventar informações.

Não inventar acusações.

Não transformar alegações em fatos.

Não utilizar "crime cometido" quando o material original tratar de investigação, acusação ou alegação.

Sempre diferenciar:

investigação;

acusação;

denúncia;

condenação;

absolvição;

decisão judicial;

anulação;

arquivamento;

fato documentado.

Quando uma informação tiver fonte, permitir apresentar a fonte original.

O objetivo é que o site tenha aparência provocativa e investigativa, mas o conteúdo permaneça documental e verificável.

18. SENSAÇÃO FINAL

Quando alguém entrar no site, NÃO quero que pareça que entrou em uma página comum de venda de PDF.

Quero que a sensação seja:

"Estou entrando em um arquivo investigativo."

O usuário deve sentir que está abrindo documentos, descobrindo informações e navegando por uma investigação digital.

Visualmente, quero algo entre:

arquivo confidencial + investigação jornalística + documentário político premium + thriller investigativo.
